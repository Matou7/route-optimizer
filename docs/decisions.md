# Journal des décisions

Ce fichier conserve les décisions produit et les points encore ouverts.

## Décisions actées

### D-001 — Application indépendante
Route Optimizer est une application mobile autonome, pas une simple surcouche à Waze ou à une autre application de navigation.

### D-002 — Priorité à la gratuité
Pas d'API payante, abonnement, publicité ou service cloud payant dans la V1. Toute dépendance doit être évaluée selon son coût réel et ses conditions d'utilisation.

### D-003 — Pas de compte utilisateur
La V1 ne nécessite pas de compte ni de synchronisation cloud.

### D-004 — Pas de Firebase
Aucun besoin actuel ne justifie Firebase.

### D-005 — Pas de guidage vocal
La navigation V1 reste visuelle.

### D-006 — Pas de signalements communautaires
Les événements proviennent de sources de données identifiées, pas de contributions d'utilisateurs.

### D-007 — Validation humaine
Toute proposition de changement d'itinéraire doit être acceptée par l'utilisateur avant application.

### D-008 — Détour maximal
Le détour supplémentaire est limité à 15 km par défaut.

### D-009 — Données honnêtes
Les informations trafic peuvent être partielles ou absentes. L'application doit montrer leur provenance et leur fraîcheur, sans inventer de certitude.
